# Codex

The CueFrame plugin carries the skills and the hosted MCP server together:

```
codex plugin marketplace add cueframe-ai/cueframe-mcp
codex plugin add cueframe@cueframe
```

Then ask Codex to run `get_account` to confirm the connection, and hand it footage or the video you want to make. Server-only, without the skills: put `examples/cursor/mcp.json`'s block in Codex's `mcp.json`.
