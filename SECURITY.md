# Security Policy

Please report vulnerabilities to **security@cueframe.ai** — do not open public
issues, discussions, or pull requests for security reports.

Include the affected endpoint, tool, package, or commit; a minimal
reproduction; the impact you believe it has; and any relevant `x-request-id`.
Please redact credentials, private media, and customer data. We acknowledge
reports within 48 hours and keep reporters informed through the fix.

Scope includes the hosted API (`api.cueframe.ai`), the MCP server, published
packages, desktop application, and this repository. Test only accounts and
media you control, avoid actions that degrade service, and stop once you have
demonstrated impact. We will coordinate disclosure timing with you after we
have reproduced and addressed the report.
